Entry for the [make.fun bounty](https://make.fun/bounty/u-daring-gecko-25-one-line-zero-use-the-useless-01ca1c68): one original line, at most 200 characters, naming a hilariously useless superpower.

`main.py` (stdlib only, deterministic) writes the line to `/output/entry.txt`:

> I can teleport anywhere in the world, but only to places I've already been, and only if I was going to walk there anyway.

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
